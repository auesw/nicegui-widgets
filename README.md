# nicegui-widgets

A collection of widgets to be used on nicegui projects

## DropdownCountryFlagsWidget
A dropdown selection of flags that inherits from nicegui's ui.dropdown_button. By default it only shows two flags, because of my personal needs, but it should be easy enough to include more flags. This module also contains a simple wrapper for the countries.dev API, suited exclusively for the needs of the module.

## CurrencyWidget
A custom widget to input currency with symbol based on a dropdown list of flags
